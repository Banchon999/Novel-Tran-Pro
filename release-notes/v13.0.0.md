# NovelTrans v13.0.0

ดาวน์โหลด **NovelTrans-v13.0.0.zip** ด้านล่าง → แตกไฟล์ → เปิดด้วย `serve.sh` (Termux) หรืออัปโหลดขึ้นเว็บโฮสต์ใดก็ได้
ข้อมูลเดิมในเครื่องไม่หาย (เก็บใน IndexedDB ของเบราว์เซอร์) · แนะนำกด 💾 Backup ทั้งหมด ก่อนอัปเดต

## ✨ หน้าตาใหม่ — Pro Tool
- พื้นเทากลาง + สีน้ำเงินสีเดียว · ตัวหนังสือรองสว่างขึ้น อ่านง่าย (ผ่านเกณฑ์ WCAG AA)
- ฟอนต์ **IBM Plex Sans Thai** (เลิกใช้ Cinzel) · ตัวเลข/ต้นทุนเป็นฟอนต์ mono
- **แถบแท็บย้ายลงล่างจอ** เป็นไอคอน + ชื่อ กดด้วยนิ้วโป้งได้ถนัด
- หน้าแปล: ปุ่มหลัก **แปลตอนนี้** ปุ่มเดียว · โหลดตอน / QA / ค้นหา / ส่งออก เป็นไอคอน · ตัวเลือกโมเดล/สไตล์อยู่แถวเดียว เลื่อนได้
- แถวปุ่มเครื่องมือทุกแท็บเป็นแถวเดียว เลื่อนซ้าย-ขวา (ไม่ล้นหลายบรรทัด)
- แถบเตือนสำรองข้อมูลใหม่ (ปุ่ม **สำรองเลย**)
- อยากได้ธีมทองเดิม: 🎨 Theme Editor → **Dark Gold (ธีมเดิม)** · ใครเคยบันทึกธีมเองยังได้ธีมนั้นเหมือนเดิม
- ระบบแปลไม่เปลี่ยน ปุ่มทุกปุ่มทำงานเหมือนเดิม
