# NovelTrans v14.0.0

ดาวน์โหลด **NovelTrans-v14.0.0.zip** ด้านล่าง → แตกไฟล์ → เปิดด้วย `serve.sh` (Termux) หรืออัปโหลดขึ้นเว็บโฮสต์ใดก็ได้
ข้อมูลเดิมในเครื่องไม่หาย (เก็บใน IndexedDB ของเบราว์เซอร์) · แนะนำกด 💾 Backup ทั้งหมด ก่อนอัปเดต

## 🌐 ใช้บนเว็บได้แล้ว + บัญชีผู้ใช้ + ⭐ Premium
- **บัญชี (ไม่บังคับ):** สมัครด้วยอีเมลหรือ Google · ไม่สมัครก็ใช้แบบใส่ API Key เองได้เหมือนเดิมทุกอย่าง
- **⭐ Premium:** แปลได้ทันทีโดยไม่ต้องมี API Key — เลือก provider "⭐ NovelTrans Premium"
  - มีโควต้า AI รายเดือน แสดงในเมนู ☰ · รีเซ็ตต้นเดือน
  - กด **⭐ ขอ Premium** ในเมนู ☰ แล้วฝากช่องทางติดต่อ แอดมินจะเปิดสิทธิ์ให้
- **Sync นิยายข้ามเครื่อง:**
  - Premium → sync ขึ้นคลาวด์อัตโนมัติ
  - ผู้ใช้ฟรี → กด 🔗 เชื่อม Google Drive (เก็บใน Drive ของคุณเอง ในโฟลเดอร์ซ่อนของแอป)
  - แก้ทั้งสองเครื่องพร้อมกัน → ระบบถามว่าจะใช้ฝั่งไหน และเก็บอีกฝั่งเป็นสำเนาไว้ ไม่มีข้อมูลหาย
  - sync สำเร็จ = นับเป็นการ Backup (แถบเตือน Backup หายเอง)

## 📦 ไฟล์ zip
- เปิดจากไฟล์ zip / โฮสต์ static ทั่วไป → ไม่มีระบบบัญชี ใช้งานแบบเดิมทุกอย่าง (บัญชี/Premium ใช้ได้บนเว็บที่ deploy บน Vercel)
