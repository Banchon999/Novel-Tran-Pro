# NovelTrans v12.5.0

ดาวน์โหลด **NovelTrans-v12.5.0.zip** ด้านล่าง → แตกไฟล์ → เปิดด้วย `serve.sh` (Termux) หรืออัปโหลดขึ้นเว็บโฮสต์ใดก็ได้
ข้อมูลเดิมในเครื่องไม่หาย (เก็บใน IndexedDB ของเบราว์เซอร์) · แนะนำกด 💾 Backup ทั้งหมด ก่อนอัปเดต

## ✨ ใหม่
- **📖 อ่านเต็มจอ + Prefetch กลับมาแล้ว** — ปุ่ม ⛶ เต็มจอ (แท็บอ่าน/แก้ไข), 📖 อ่านต่อ (แท็บตอน), 📖 อ่าน (หน้าดูตอน) · แปลตอนถัดไปล่วงหน้าระหว่างอ่าน
- **🗺 Speaker Map + ตรวจเพศหลังแปล** — ระบุผู้พูดทุกบทพูดก่อนแปล, เลือก ครับ/ค่ะ ตามระดับภาษา (สุภาพ/ภาษาปกติ), ตรวจ เขา/เธอ ในบรรยาย 2 รอบ
- **รายการโมเดลเหลือเฉพาะโมเดลข้อความ** (ตัดโมเดลภาพ/เสียง/วิดีโอ/embedding ออก) · เพิ่ม Gemini 3.x · ราคาจริงจาก OpenRouter
- ทดสอบ key OpenRouter แสดงเครดิตคงเหลือ · ผล QA ค้างไว้ใต้คำแปล · Export คลังศัพท์มีคอลัมน์เพศ

## 🐞 แก้บั๊ก
- กู้ไฟล์ **Backup ทั้งหมด (1-click)** กลับไม่ได้ → กู้ได้แล้ว · ไฟล์ JSON ขาดท้ายซ่อมได้
- Context Manager เปิดแล้วพัง
- 도련님 แปลเป็น "คุณหนู" (ผิดเพศ) ทุกตอน → "คุณชาย"
- AI แปลชื่อตอนแล้วใส่ผิดตอน (หลัง Re-number)
- ปุ่ม ลบ/อ่าน/Split ในหน้าดูตอนหลุดจอบนมือถือ
- Auto Glossary ขึ้น "ไม่พบ" กับโมเดลที่คิดก่อนตอบ (เช่น Gemini 3.5 Flash Lite) → ไม่ถูกตัดแล้ว + บอกสาเหตุจริง
- EPUB ชื่อตอนเบิ้ล · Clean Source ลบ base64 ไม่หมด · CSV คลังศัพท์ import กลับผิดช่อง
- คำแปลถูกตัดกลางคัน/AI ส่งต้นฉบับกลับมา แต่ขึ้นว่าแปลเสร็จ
- โหลดตอนมาแปลแล้วกดบันทึกไม่ได้ · ต้นทุน Gemini ไม่นับ token ที่ใช้คิด
