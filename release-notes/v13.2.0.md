## 📖 สกัดคำศัพท์แม่นขึ้น — Prompt แยกตามภาษา
- เดิมใช้ Prompt ภาษาเกาหลีตัวเดียวแล้วดัดแปลงไปใช้กับจีน/อังกฤษ ตอนนี้แต่ละภาษามี Prompt ของตัวเอง:
  - **เกาหลี** — ถอดชื่อแบบสำนักพิมพ์ไทย (최 ชเว · 박 พัค)
  - **จีน** — ถอดเสียงจากพินอิน + ตารางแซ่ที่ใช้บ่อย (赵 จ้าว · 无 อู๋) · สำนัก/ขั้นพลัง/วิชาแปลความหมาย (ไม่ถอดเสียงดิบ)
  - **อังกฤษ** — ถอดชื่อตามแนวราชบัณฑิต · ศัพท์เกมใช้คำที่คนไทยคุ้น
- ทดสอบกับ AI จริง (ต้นฉบับจีน): คำแปลไทยตรงเฉลยจาก 2–3/7 เป็น 6–7/7 · ไม่ดึงทั้งวลีมาเป็นคำ (เช่น ชื่อ+ยศรวมกัน) อีก
- หน้าแก้ Prompt (🤖 Auto → ✏ Prompt) เลือกภาษาได้ บันทึกแยกภาษา และเตือนเมื่อ Prompt มีกฎของภาษาอื่นปน

## 🏯 นิยายเกาหลีที่ใช้ชื่อจีน → เสียงเกาหลีเสมอ
- แซ่ซ้อน: 제갈 เจกัล · 남궁 นัมกุง · 모용 โมยง · 황보 ฮวังโบ · 독고 ทกโก · 영호 ยองโฮ ฯลฯ
- สำนัก/สถานที่: 화산 ฮวาซาน · 소림 โซริม · 무당 มูดัง · 아미 อามี · 사천 ซาชอน
- ถ้า AI ยังให้ชื่อแบบจีน (เส้าหลิน, ถัง, หนานกง) ระบบแก้เป็นเสียงเกาหลีให้ตอนลงคลังอัตโนมัติ
- แนว 📚 มู่หลินเกาหลี ปรับตามนี้แล้ว

## 🌏 ทุกขั้นตอนใช้ภาษาตามต้นฉบับจริง
- ระบบตรวจภาษาจากข้อความที่กำลังแปล/สกัดคำ แล้วใช้กฎภาษานั้นทั้งการแปล การสกัดคำ การระบุผู้พูด และ 🧠 AI วิเคราะห์คลังศัพท์
- ตั้งค่าภาษาไว้ไม่ตรงกับต้นฉบับ → ระบบใช้กฎที่ถูกให้ และแจ้งเตือน 1 ครั้ง
- แนวนิยายจะใส่เฉพาะเมื่อภาษาตรงกัน (แนวเกาหลีไม่ปนกับต้นฉบับจีน)
