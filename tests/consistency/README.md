# ชุดทดสอบความต่อเนื่องของคำแปล (เหมือนนักแปลคนเดียว)

วัดว่าคำศัพท์ประจำแนว (ทับศัพท์หรือแปล) และสำนวน **เหมือนเดิมทุกตอน/ทุกรอบ** ไหม — ผ่านแอปจริง + AI จริง

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `scenarios.json` | บทจำลอง 3 ตอน คำที่แปลได้หลายแบบวนซ้ำ (데스나이트 소드마스터 오러 마수 게이트 헌터 회귀 성녀) + `terms` = รูปแบบคำแปลที่เป็นไปได้ + `styleSheet` ตัวอย่างคู่มือการแปล |
| `run-consistency.js` | แปลทั้ง 3 ตอน × N รอบ (WS ใหม่ทุกรอบ คลังเริ่มว่าง preset ไม่มี `{context}` temp 1) แล้วนับว่าแต่ละคำใช้กี่แบบ |

```bash
node tests/consistency/run-consistency.js google/gemini-3.1-flash-lite B 3            # โค้ดปัจจุบัน
STYLE=1 node tests/consistency/run-consistency.js google/gemini-3.1-flash-lite C 3    # + คู่มือการแปล
STABLE=0 …   # ปิดแปลแบบคงที่ · BASE=http://localhost:8096 … # ทดสอบแอปเวอร์ชันอื่น (เช่น worktree ของเวอร์ชันเก่า)
```
ค่าใช้จ่าย ~$0.01 ต่อ 3 รอบ (Gemini 3.1 Flash Lite) · ผลอยู่ใน `out/` (ไม่ commit)

## ผล (2026-10-03, Gemini 3.1 Flash Lite, 3 รอบ × 3 ตอน)
| ชุด | คำเดียวตลอด (ต่อเรื่อง) | คำแปลตอนเดียวกันข้ามรอบเหมือนกัน |
|---|---|---|
| A เวอร์ชันเดิม v12.5.0 (temp 1, ไม่มีบริบท) | 성녀 ตอนแรก "ซองนยอ" แต่คลังได้ "นักบุญหญิง" → ตอนต่อไปเปลี่ยนคำ | 57% (ต่ำสุด 27%) |

| C ใหม่ + คู่มือการแปล | 8/8 และเหมือนกันทุกรอบ | 87% (ต่ำสุด 77%) |
